# Соответствие требованиям первичных артефактов

Основание: предоставленные пособие, памятка и пример синтаксиса PlantUML.
Из примера использован формат сообщений, ответов, `alt` и `loop`; его бизнес-процесс не переносится.
Репозитории одногруппников использованы как ориентир состава файлов и отображения изображений в README.

| Требование памятки | Где выполнено |
| --- | --- |
| Общий сиквенс: переполнение, занятость, назначение | [sequence-main](diagrams/sequence-main.puml) |
| Happy Flow | [sequence-happy](diagrams/sequence-happy.puml) и ветви общего сиквенса |
| Отказ / выбивание | [sequence-overflow](diagrams/sequence-overflow.puml): Д1ОО5 отказывает новой заявке, выбивания нет |
| Постановка в буфер | sequence-main, sequence-happy, sequence-overflow |
| Выборка из буфера, постановка на прибор | [sequence-batch](diagrams/sequence-batch.puml) |
| Расшифровка кодов рядом с взаимодействиями | Примечания и сообщения всех сиквенсов |
| Ответы на запросы | Пунктирные response-сообщения `-->` |
| Триггеры диспетчеров | Генерация, успешная запись и завершение печати |
| Классы, методы, аргументы и ссылки | [classes](diagrams/classes.puml) |
| Инкапсуляция | Приватные поля `-`, публичные методы `+` в classes |
| Flowchart с дорожками и альтернативами | [обработка событий](diagrams/flowchart.puml) и [подробный выбор](diagrams/flowchart-dispatch.puml) |
| Фиксированные пакеты, один пакет для всех приборов | sequence-batch, classes, flowchart и [правила](model-rules.md) |
| Формализованная схема ОД2 | [formal-scheme](diagrams/formal-scheme.puml) |
| Статистика, календарь и отображение | classes, flowchart и правила модели |
| Расшифровка варианта в README | [README](../README.md) |
| Общая / зонная память | Правила модели и оригинальный бизнес-домен |

ArchiMate 3.0 опционален. Временная диаграмма по памятке не нужна.
Реализация, экспериментальная оптимизация и экономическое обоснование относятся к следующим этапам.
