# Как читать диаграмму классов Java

В модели восемь классов. Main отдельно читает настройки и отображает результаты.
В прямоугольнике сверху — название, посередине — поля, снизу — методы.
Минус означает private; методы модели доступны внутри пакета, Main.main — публичный вход.

| Класс | Назначение |
| --- | --- |
| Simulation | Модельное время, календарь, источники, принтеры и запуск диспетчеров |
| Source | Создание заявки и расчёт следующего поступления Exp(λ) |
| PrintJob | Номер, источник, состояние и временные отметки заявки |
| Buffer | Ограниченная очередь: запись в конец, снимок, извлечение со сдвигом |
| AdmissionDispatcher | Приём новой заявки или отказ при переполнении |
| SelectionDispatcher | Фиксированный пакет и назначение принтеров по номеру |
| Printer | Печать одной заявки за случайное время U(a,b) |
| Statistics | Счётчики, средние времена, дисперсии и занятость принтеров |

admit(job, actions) принимает заявку и записывает действия в журнал шага.
Возвращаемый boolean означает, принята заявка или отклонена.
dispatch(time, actions) назначает заявки и возвращает записи новых завершений.
Simulation добавляет эти события в свой календарь.

У диспетчера выбора memberIds — весь фиксированный состав пакета,
pendingIds — ожидающие назначения ID, inFlightIds — печатаемые ID.
Новые поступления пакет не пополняют. onCompleted удаляет завершённый ID;
когда ожидающих и печатаемых нет, пакет закрывается.

Все поля private. snapshot()/view() отдаёт неизменяемые снимки.
По снимку очереди можно построить таблицу, но нельзя изменить настоящий буфер.
Record-типы Config, View, Event описывают данные, не дополнительные диспетчеры.

Сплошные стрелки — хранимые ссылки; ромб у модели — её компоненты;
белый ромб у буфера — хранение заявок. 0..N — вместимость буфера,
0..1 — не более одной заявки на принтере, 1..m — несколько принтеров.

Для защиты: источник создаёт заявку, диспетчер постановки помещает её в буфер,
диспетчер выбора назначает принтер, модель управляет событиями, статистика собирает результаты.

В дополнительных старых схемах BatchManager/Batch — роли внутри SelectionDispatcher,
PrinterPool — его список принтеров, EventCalendar — календарь Simulation.
