# Диаграммы

| Файл | Назначение |
| --- | --- |
| sequence-main | Полный цикл и альтернативы |
| sequence-happy | Нулевое ожидание в свободной системе |
| sequence-overflow | Д1ОО5 — отказ новой заявке |
| sequence-batch | Подробный алгоритм Д2Б5 и Д2П1 |
| classes | Классы, поля, методы, ссылки |
| flowchart | Блок-схема с дорожками |
| flowchart-dispatch | Подробная блок-схема выбора и всех его альтернатив |
| formal-scheme | Формализованная схема СМО для ОД2 |

Для каждой диаграммы есть `.puml`, `.svg` и `.png` с одним именем.
SVG удобно увеличивать, PNG удобно вставлять в отчёт, PlantUML служит редактируемым исходником.
Описание поведения: [правила модели](../model-rules.md).
