| Элемент СМО | Сущность бизнес-домена | Назначение |
| --- | --- | --- |
| Источник | Подразделение компании: бухгалтерия, отдел кадров, аналитический отдел | Создаёт поток заданий на печать документов и передаёт их в систему. Источник бесконечный, поток пуассоновский (ИБ, ИЗ1). |
| Заявка | Задание на печать комплекта документов | Единица работы, которая должна быть принята системой. Ожидает в очереди и печатается целиком на одном принтере. |
| Буферная память | Общая ограниченная очередь заданий | Хранит задания, ожидающие печати. По Д1ОЗ2 запись выполняется в конец очереди; после извлечения последующие задания сдвигаются. Можно реализовать с помощью базы данных. |
| Прибор | Сетевой принтер | Выполняет одно задание за раз. Время печати моделируется равномерным законом распределения согласно ПЗ2. |
| Диспетчер постановки | Алгоритм приёма и размещения заданий | Срабатывает при поступлении нового задания. Ставит его в конец буфера по Д1ОЗ2. Если буфер заполнен, применяет Д1ОО5: отклоняет новую заявку, сохраняя уже принятые. |
| Диспетчер выбора | Алгоритм планирования и назначения печати | После записи в буфер или завершения печати выбирает задания фиксированного пакета по приоритету подразделения (Д2Б5). Новый пакет начинает после завершения текущего. Принтер выбирает по номеру (Д2П1). |
| Отказ | Отклонение нового задания без печати | При переполнении буфера вновь пришедшее задание покидает систему. Оно учитывается в числе сгенерированных заявок и отказов; очередь не изменяется. |
| Обслуживание | Печать комплекта документов | Принтер печатает задание в течение случайного времени, после чего оно считается выполненным и покидает систему. Новые задания не дополняют текущий пакет. |
| Выход из системы | Выполненное или отклонённое задание | Задание покидает систему после успешной печати либо в результате отказа при поступлении. |
